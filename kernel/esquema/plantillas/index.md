# Plantillas OKF base

Una plantilla por tipo del catálogo base (ver `kernel/esquema/okf.md`). Los skills SIEMPRE parten de estas plantillas. Las plantillas de tipos propios del usuario viven en `/plugins/plantillas/` (las crea `/x-crear-plantilla`).

* [reunion.md](reunion.md) - Nota procesada de reunión.
* [decision.md](decision.md) - Registro de decisión con contexto y alternativas.
* [pregunta.md](pregunta.md) - Duda abierta con estado, responsable y avances.
* [persona.md](persona.md) - Ficha de persona: qué sabe, pendientes, historial.
* [sistema.md](sistema.md) - Ficha de sistema, herramienta, producto o proceso de la organización.
* [lineamiento.md](lineamiento.md) - Estándar, política o regla de trabajo.
* [diagrama.md](diagrama.md) - Diagrama versionado con decisiones y supuestos.
* [contexto-iniciativa.md](contexto-iniciativa.md) - CONTEXT.md de cada proyecto.
* [plan.md](plan.md) - PLAN.md de cada proyecto: tareas por fase con responsable, estado y límite.
* [insumo.md](insumo.md) - Documento recibido convertido a markdown (lo genera a-markdown.py).
* [glosario.md](glosario.md) - Término o sigla interna.
